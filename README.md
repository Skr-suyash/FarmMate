# Farm Mate

FarmMate is a smart farming assistant app designed using Flutter, FlutterFlow, Google Gemini, Firebase to support farmers with real-time agricultural guidance. It offers features like crop recommendations, weather updates, pest and disease alerts, and market price tracking. With a user-friendly interface and local language support, FarmMate empowers farmers to make informed decisions, improve yield, and increase profits.

## Features
- 🌿 Image AI-Based Disease Detection: Upload a plant photo, and our AI model identifies diseases with treatment suggestions.
- 🌱 Soil Sync: Real-time monitoring of pH, moisture, conductivity, and NPK levels for optimal soil health.
- 💧 Water Level Tracking: Real-time monitoring to ensure proper irrigation and water management.
- 🌾 Yield Predictor: Accurate yield estimation based on soil data and crop type.
- 🌦️ Weather Forecast: Real-time updates and weekly forecasts.
- 🗺️ Nearby Store Finder: Find seed, fertilizer, and equipment stores easily.
- 🌐 Multi-Language Support: Available in 10 regional languages for better pan India accessibility.
- 🗣️ Gemini AI Chatbot: Get instant answers to farming-related queries.

## Future Vision
We aim to build a complete end-to-end marketplace for farmers and integrate IoT for real-time soil health and water level tracking, making precision agriculture more accessible.

## Getting Started
1. Add all api keys like Gemini, Firebase, Maps API
2. FlutterFlow projects are built to run on the Flutter _stable_ release.
3. Active internet connection is required to perform AI analysis of features such as soil health predictor and leaf disease predictor.
